Upload photos into this folder. They show up on the Photos page on their own.

jpg, png, webp, and gif all work.

Optional caption — add one line to `_data/captions.yml`:

    your-file-name.jpg: "What is in the picture"

Skip that step if the photo does not need a caption.

To control order, start the filename with the date. Newest shows first:

    2026-06-22-katahdin-summit.jpg
